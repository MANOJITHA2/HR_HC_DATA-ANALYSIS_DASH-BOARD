HR Headcount Analysis Dashboard | Power BI
📌 Project Overview

Organizations often face challenges in understanding employee data due to fragmented information across departments, roles, and locations.
This HR Headcount Analysis Dashboard, developed using Power BI, helps convert raw HR data into clear, actionable insights by visualizing workforce distribution and trends across multiple dimensions.

The dashboard enables HR teams and management to explore employee data interactively, identify workforce patterns, and support informed decision-making.

🎯 Project Objectives

Provide a clear view of employee headcount across the organization

Analyze workforce distribution by business unit, department, job title, age group, gender, and country

Track Year-on-Year hiring and attrition trends

Enable dynamic analysis using interactive slicers

Ensure transparency with last data refresh information

🧩 Dashboard Components
🔹 1. Headcount Trend Analysis

Visualizes Year-on-Year Headcount growth and Attrition

Helps identify hiring patterns, workforce expansion, and attrition fluctuations over time

🔹 2. Headcount by Business Unit

Displays employee distribution across key business units such as:

Sales

HR

IT

Services

Enables comparison of workforce strength across units

🔹 3. Age Group Distribution

Analyzes employee headcount across different age groups

Helps understand workforce demographics and generational composition

🔹 4. Gender-Based Headcount Analysis

Visual representation of employee distribution by gender

Supports diversity and inclusion insights

🔹 5. Job Title Breakdown

Shows headcount distribution across various job roles

Helps identify role concentration and organizational hierarchy

🔹 6. Department-Wise Headcount

Provides visibility into employee distribution across departments

Useful for workforce planning and departmental analysis

🔹 7. Country-Wise Headcount

Displays employee presence across different countries

Enables geographical workforce comparison

🎛 Interactive Slicers for Enhanced Analysis

The dashboard includes multiple slicers for dynamic filtering:

🏢 Department

🌍 Country

👤 Employee Full Name

These slicers allow users to drill down into specific employee segments and analyze data across all visuals in real time.

🔄 Data Refresh Information

A dedicated visual displays the last data refresh date and time

Ensures users are aware of data accuracy and freshness
